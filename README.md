# 🚀 DSA-Check-List

Welcome to the **DSA-Check-List** repository! This repository provides a highly structured and comprehensive roadmap for mastering Data Structures and Algorithms (DSA), heavily inspired by the popular takeUforward (TUF+) DSA sheet. 

Whether you are preparing for technical interviews at top tech companies or just starting your competitive programming journey, this checklist will help you track your progress systematically.

## 📂 Repository Contents

- `DSA Checklist.pdf`: The core checklist document containing an exhaustive list of DSA topics and must-do problems. You can use it to track problems you've **Completed**, the **Revision Count**, and whether you need to **Revisit** them.

## 🎯 Comprehensive Topic Coverage

The checklist is meticulously categorized from fundamental to advanced topics, ensuring you build a solid foundation before tackling complex algorithms. 

### 🔹 Fundamental Data Structures
- **Arrays**: Medium and Hard problems (e.g., Kadane's Algorithm, Next Permutation)
- **Hashing**: Subarrays with given sums and XORs
- **Linked Lists**: Singly & Doubly Linked Lists fundamentals, advanced manipulations, and logic building
- **Stacks & Queues**: Implementation using different DS, Monotonic Stack, and FAQs
- **Strings**: Advanced algorithms (Z-function, KMP, Rabin Karp)

### 🔹 Core Algorithms & Techniques
- **Binary Search**: 1D Arrays, 2D Matrices, and answer-on-range problems (e.g., Book Allocation, Aggressive Cows)
- **Recursion**: Combinations, Subsets, and Backtracking (N-Queen, Sudoku Solver, Rat in a Maze)
- **Sliding Window & 2 Pointers**: Substring and Subarray problems
- **Bit Manipulation**: Core tricks and math
- **Greedy Algorithms**: Easy to Hard, including scheduling and intervals

### 🔹 Advanced Data Structures
- **Trees**: Binary Trees (Traversals, Construction, Views) and Binary Search Trees (BST)
- **Heaps**: Implementation, Heap Sort, and stream problems
- **Graphs**: Traversals (BFS/DFS), Cycle Detection, Topological Sort, Shortest Paths (Dijkstra, Bellman-Ford, Floyd Warshall), and Minimum Spanning Trees (MST)
- **Tries**: Implementation and advanced XOR problems

### 🔹 Dynamic Programming (DP)
- **1D DP**: Basic recurrences
- **DP on Grids**: Pathfinding
- **DP on Subsequences & Strings**: LIS, LCS, Edit Distance
- **DP on Stocks**
- **MCM DP**: Matrix Chain Multiplication variations

### 🔹 Mathematics
- Sieve of Eratosthenes, Prime Factorization, etc.

## 🚀 How to Use This Checklist

1. **Download the PDF**: Click on `DSA Checklist.pdf` and download it to your local machine, or print it out.
2. **Solve & Track**: For each problem you solve, mark it as `Completed`.
3. **Revise**: Keep track of your `Revision Count` for spaced repetition.
4. **Revisit**: Mark problems that were tricky as `Revisit` so you can practice them again before an interview.
